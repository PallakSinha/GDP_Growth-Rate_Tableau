# 🌍 Global GDP Economic Analysis (2000–2025)

An interactive Tableau dashboard exploring global economic output, country-level GDP comparisons, and historical GDP trends from 2000 to 2025.

## 📌 Project Overview

This project uses **Tableau** to visualize and explore GDP data across countries and continents over a 26-year period. It brings together geographic visualization, economic rankings, and time-series analysis to make global economic patterns easier to understand.

The dashboard is designed to support exploratory analysis of economic performance, identify leading economies, and examine India's GDP trajectory over time.

## 🎯 Objectives

- Explore the distribution of GDP across countries and continents.
- Compare the world's top 10 economies based on GDP.
- Analyze historical GDP trends between 2000 and 2025.
- Examine India's GDP trajectory over the study period.
- Communicate economic patterns through clear, interactive visualizations.

## 🗂️ Dataset & Data Preparation

The workbook uses a dataset named `gdp_2000_2025.csv`, containing country-level GDP information across the years 2000–2025.

The data includes the following fields:

- `Name of country` — Country name
- `Continent` — Continent classification
- `Year` — Year of observation, derived from the original year columns
- `GDP ($)` — GDP value in the dataset

The original year-wise columns are pivoted into a long-format structure, allowing the data to be analyzed across years using Tableau.


## 🚀 How to Explore the Project

1. Download or clone this repository.
2. Open `GDP_2000-2025_Analysis.twb` using Tableau Desktop.
3. If prompted, reconnect the data source to `gdp_2000_2025.csv`.
4. Navigate to the dashboard and individual worksheets.
5. Explore the geographic distribution, country rankings, and historical trends.
